The goal

Free tools. No subscriptions, ever.

Streaming software has drifted toward monthly fees, paywalled features and cloud accounts. LC Tools are built to break away from that. The goal is for every LC tool to be free and open source, running on your own PC, with nothing to subscribe to.

  • Free and open source

    Every tool is free to download and use. The goal is to publish them as open-source projects anyone can read, learn from and improve.

  • No subscriptions, ever

    No monthly fee, no premium tier and no features held back. Donations are always optional and never unlock anything.

  • Inspired by AnkhBot

    LCBot is inspired by the original AnkhBot: a desktop bot you owned and ran yourself, from before it became Streamlabs Chatbot.

Safe, direct downloads

Every download button links straight to the installer on the official GitHub release, the same file the apps' built-in updaters use.

"Windows protected your PC"?

The installers aren't code-signed yet, so SmartScreen may warn you. Click More info → Run anyway. A signing certificate is the first donation goal.

Updates built in

LCClips and LCBot check GitHub for new versions on launch, so you only need to download once.

Like the tools?

They're free with no subscriptions, ever. Optional donations pay for code signing and time to build the next LC tool.
